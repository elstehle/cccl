### T?: ballot-per-slot warp-aggregated tickets cost about 150 cycles per tile slot in a dependent chain, per-item tickets pipeline, aggregation loses by 24 to 73 percent at k up to N over 4
applies to: emission and partition stages of every block selection (B1 to B6, N6), the "ballot prefix, per-warp atomic base" emission of the N6 and B4 idea cards, warp scope with several slots per lane
measured: block_topk_air radix select with an index-only epilogue, 256 threads, B200 umbriel-b200-068, CUDA 13.4.92, 2026-10-25, harness latency chain slope, file state/results/opt-B1/B1_idxw_vs_B1_idx_focus_idxw1_20261025_130958.json (card B1_idxw_b200_20261025_1). Per-slot aggregation (one ballot per slot and warp, one atomic with return by lane 0 when the ballot is nonzero, shuffle broadcast, popc rank) against one atomic per selected item: bf16 N 1024 k 16 2317 against 1767 cycles, k 64 2590 against 1877, fp32 N 4096 k 64 6501 against 4591, bf16 N 32768 k 16 59063 against 16461 (IPT 128, 3.6 times slower). Throughput 334 against 409 Gelem per s at bf16 N 1024 k 16, 155 against 459 at N 32768.
evidence: SASS of the latency kernel 1008 against 656 instructions at bf16 N 1024 and 21576 against 10296 at N 32768, the per-slot body is VOTE, POPC, predicated ATOMS.ADD with return, SHFL.IDX, POPC, STS inside a BSSY to BSYNC region per slot, so slot s + 1 waits for slot s. Source approaches/B1/block_topk_b1.cuh, ticket_mode::warp_aggregated.
how to use: Emit selected items with one independent atomic per item (the atomic unit overlaps them, T9 and T10) unless the selected items per slot are many (k of order N over 2). Never guard an aggregated atomic with `if (ballot != 0)` in an unrolled slot loop: the guard serializes the slots. The chain per slot is ballot 27, popc 23, atomic with return 55, shuffle 30 plus the rank and store, about 150 cycles, times the items per thread.
caveats: The unguarded form (always issue, add zero, all ballots first) was not measured and would still serialize 8 warps x IPT atomics with return on one address. At warp scope with one slot per lane the aggregation is a single chain and may pay, not measured here.
