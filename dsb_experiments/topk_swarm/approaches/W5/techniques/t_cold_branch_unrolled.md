### T?: a cold network under a warp-uniform branch inside an unrolled round loop is replicated per iteration and the instruction fetch then costs more than the work it saves, roll the loop around it
applies to: every extraction round loop with a rare refill, retry or slow path inside it (N7 two-level lists, W2 and B2 rounds with a conditional refill, W5 and B4 fallbacks placed inside a loop, N6 and W3 passes with a conditional narrowing), all scopes, all key widths
measured: N7_twolevel (W2 packed rounds on a head of 8 plus an unsorted remainder, refill network under `if (__any_sync(need))` after every block of rounds), bf16, B200 umbriel-b200-028 sm_100 nvcc 13.4.92 2026-10-25, harness latency chain slope, control W2_packed_v3 in the same lock section. Block loop unrolled over the K / 4 blocks: N 512 k 16 1146 cycles, k 32 2265, k 64 5327 (70 to 96 per round), N 1024 k 16 1855, k 32 3992, k 64 9903 against W2 7308 (134 to 185 per round), N 2048 k 64 15982 against 10071. Same source with the block loop rolled (`#pragma unroll 1`, blocks of 4): N 1024 k 64 7182, N 2048 k 64 12614, the round 70, 106 and 190 cycles at IPT 16, 32 and 64 for a second reason (next entry). Files state/results/opt-W5/N7_twolevel_vs_W2_packed_v3_focus_n7a_20261025_151124.json (unrolled) and N7_twolevel_vs_W2_packed_v3_focus_n7b_20261025_151825.json (rolled), source harness/adapters/N7_impl.cuh at 9e60d70f4d (unrolled) and f3d46611e3 (rolled), branch exp/topk-swarm/W5.
evidence: cuobjdump of the unrolled build at bf16 N 1024 k 64: throughput kernel 5720 instructions with 3737 VIMNMX and 15 VOTE (W2_packed_v3: 2792 and 382), latency kernel 11368 instructions (about 180 KB of code, the warm-up copy and the chain copy of the primitive each carry 15 copies of the 230-instruction refill), 0 BSSY, 0 bytes stack, 64 registers. The rolled build at the same cell: 1000 instructions in the throughput kernel, one copy of the refill behind a predicated BRA, same registers, no local memory. The round is the 26-cycle depth-8 redux round of T19 in both builds, the difference between 9903 and 7182 is instruction fetch.
how to use: Keep a cold path that lives inside a round loop in exactly one copy: roll the loop (`#pragma unroll 1`) around the block that contains the branch and keep only the inner block of rounds unrolled, with compile-time indices into the register arrays so nothing goes to local memory. Compare the kernel's instruction count in the batch JSON (`sass_instructions`) with the control: a round loop that is several times the control's size with the same opcode mix per round is replicating something. The cost is invisible in `-Xptxas -v` (no spills, no stack) and in the opcode mix per round.
caveats: One toolkit (nvcc 13.4.92) and one SM (sm_100). The rolled loop costs a loop branch and runtime round indices (the emission lane select and the output slot) per block, see the next entry for what that costs. The T41 shift pruning does not apply to a refilled head anyway (every head position stays live), so rolling loses nothing there, a plain W2 list must stay unrolled for the pruning.
